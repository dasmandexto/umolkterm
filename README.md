# 🦇 UmolkTerm

Веб-термінал із **zsh**, менеджером **SSH-підключень** (запам'ятовує сервери), AI-помічником та темою **Dracula**. Адаптований під телефон.

## Запуск

```bash
./start.sh                          # пароль згенерується при першому запуску і буде виведений у консоль
UMOLK_PASSWORD='мій_пароль' ./start.sh   # або задати свій (запам'ятовується, хеш scrypt)
```

Відкрити: `https://<IP>:7681` (самопідписаний сертифікат — один раз прийняти попередження браузера; `UMOLK_HTTP=1` вимикає HTTPS). Вхід за паролем, сесія 30 днів.

## Оболонка (zsh + Starship)

```bash
./shell/install.sh   # ставить ~/.zshrc та конфіги Starship (старий .zshrc зберігається як бекап)
```

Потрібні пакети: `zsh zsh-autosuggestions zsh-syntax-highlighting starship`.
Prompt автоматично перемикається на **компактний**, коли термінал вужчий за 70 колонок (телефон).
Іконки prompt відображаються завдяки вбудованому Nerd Font (`public/fonts`), нічого ставити на клієнті не треба.

## Можливості

- Вкладки: локальний zsh і кілька SSH-сесій одночасно
- Збережені SSH-сервери: пароль або приватний ключ, групи, пошук, тест з'єднання
- Швидке підключення `user@host:port` (з/без збереження)
- AI-помічник (вбудований офлайн-режим, OpenAI, Gemini — ключі в налаштуваннях)
- Мобільний режим: бічні панелі як висувні шторки, панель клавіш **Esc / Tab / Ctrl / ← ↑ ↓ → / | ~ / -**, вставка з буфера

## 🎙 Голосові команди

Кнопка 🎤 у шапці: натисніть → говоріть → натисніть ще раз → з'явиться панель із командою → **Виконати** / **Вставити** / **Ще раз**.
Небезпечні команди (`rm -r`, `dd`, `mkfs`, `reboot` тощо) підсвічуються і вимагають додаткового підтвердження.

- **З ключем OpenAI** (Налаштування) — запис іде на сервер → Whisper (`whisper-1`), команду підбирає GPT-4o-mini.
- **Без ключа** — вбудоване розпізнавання браузера (Chrome/Edge/Safari), мова вибирається в налаштуваннях.
- Мікрофон береться з **пристрою, де відкрито браузер** (телефон/ПК), а не із сервера. Браузер дає доступ до мікрофона лише на HTTPS.

## Безпека

- Усе (сторінка, API, WebSocket) закрито паролем; 5 невдалих спроб → блокування IP на 5 хв
- Cookie `HttpOnly` + `SameSite=Strict`, підписана HMAC
- Файли в `data/` мають права `600`; змінні `UMOLK_PASSWORD`, `OPENAI_API_KEY`, `GEMINI_API_KEY` не потрапляють у середовище shell
- Паролі швидкого підключення передаються через одноразовий тікет, а не в URL

> [!WARNING]
> Це доступ до shell сервера. Для використання через інтернет **обов'язково** додайте HTTPS (nginx/Caddy + certbot), бо без нього пароль іде відкритим текстом. Паролі збережених SSH-серверів лежать у `data/connections.json` у відкритому вигляді (права 600).
